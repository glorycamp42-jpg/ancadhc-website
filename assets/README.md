# assets/ — 이미지 폴더

Eugene이 채팅에서 업로드하신 실사 이미지들을 이 폴더에 저장해주세요.

## 저장 파일명 (프로토타입이 바로 참조합니다)

| 파일명 | 설명 | 사용 위치 |
|--------|------|-----------|
| `logo.jpg` | 센터 로고 (초록 원형, "코로나 양로 보건센터") | 헤더 좌측, 푸터, 히어로 상단 |
| `staff.jpg` | 스태프 단체 사진 ("환영합니다") | Why Us "가족 같은 돌봄" 카드, Team 섹션 |

## 저장 방법
1. 채팅 이미지 우클릭 → "이미지 저장"
2. 파일명을 위 표대로 정확히 지정
3. 이 폴더에 저장
4. `ancadhc-preview.html` 새로고침 (Ctrl+F5)

## 폴백 (파일 없을 때)
HTML에는 `onerror` 폴백이 있어서 파일이 없어도 Unsplash 이미지가 자동 표시됩니다. 파일 저장 후 새로고침하면 실제 이미지로 교체됩니다.
